# skills

Agentic skills by mmontes11.

## Skills

| Skill | Description |
|-------|-------------|
| [contributions-rank](contributions-rank/SKILL.md) | Rank the contributions surfaced by a batch of scouted projects against the [mmontes11/contributions](https://github.com/mmontes11/contributions) `#contribution-scoring` rubric and post the table on the parent Multica issue. |
| [contributions-scout](contributions-scout/SKILL.md) | Scout one open-source project for contributions likely to be merged — candidates, high-level plan, feasibility — posted as a comment on its Multica sub-issue. |
| [contributions-update](contributions-update/SKILL.md) | Keep the project tables of [mmontes11/contributions](https://github.com/mmontes11/contributions) current: scrape the star lists, score only the delta against the repo's `#scoring` rubric, and commit a small diff to `main`. |
| [knowledge-base-add-book](knowledge-base-add-book/SKILL.md) | Add a book to the `books/` section of [mmontes11/knowledge-base](https://github.com/mmontes11/knowledge-base) as a faithful, chapter-by-chapter study. |
| [knowledge-base-add-project](knowledge-base-add-project/SKILL.md) | Add a new tracked project or category to the `projects/` section of [mmontes11/knowledge-base](https://github.com/mmontes11/knowledge-base), or update an existing project on the maintenance run. |
| [knowledge-base-query](knowledge-base-query/SKILL.md) | Query [mmontes11/knowledge-base](https://github.com/mmontes11/knowledge-base) — projects, books, and foundational topics — by following the index tables in its root README. |
| [kubeseal](kubeseal/SKILL.md) | Seal or reseal Kubernetes Secrets into SealedSecrets using `kubeseal` for secure GitOps storage. |
| [mermaid-diagrams](mermaid-diagrams/SKILL.md) | Author and render/verify mermaid diagrams (flowchart, sequence, state, ER, C4, ...) with `mermaid-cli` (`mmdc`) and the turnkey `mermaid-render` wrapper. |
